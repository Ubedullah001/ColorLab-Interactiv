# 🎨 Color Learning Studio

Color Learning Studio is an interactive educational web application built with Streamlit.

Learn colors, mix colors, and discover beautiful new colors!

**Live App:** https://rgb-lab-color-tool.streamlit.app

---

## 🌈 Features

- Learn about Primary Colors
- Learn about Secondary Colors
- Understand basic color mixing
- Interactive Color Mixer
- Simple and beginner-friendly explanations
- Colorful and responsive design
- Works on mobile and desktop

## 🎯 Primary Colors

The three basic primary colors are:

- 🔴 Red - #FF0000
- 🟡 Yellow - #FFD700
- 🔵 Blue - #0000FF

## 🌈 Secondary Colors

Secondary colors are created by mixing two primary colors:

- Red + Yellow = Orange 🟠
- Yellow + Blue = Green 🟢
- Blue + Red = Purple 🟣

## 🧪 How It Works

1. Select first color
2. Select second color
3. See the magic! App shows you the resulting color.

**Simple Rule:** Primary + Primary → Secondary Color
